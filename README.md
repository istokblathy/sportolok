projekt címe: Sportolók
• csapattagok neve: Balazs Gergo, Istok Adam
• választott téma: Sportolók
• adatmodell rövid leírása: Kiemelkedo sportolokrol szerettunk volna irni rovid leirasokat, es kiirni a kedvenceinket
• a program funkciói: Regisztralni lehet sportolokat
• a generált oldalak rövid bemutatása: 🏠 Főoldal (index)
Kártyákon jelennek meg a sportolók, és alul két szám látszik: hány sportoló van összesen, és mennyi a kedvenc.

📋 Lista oldal (items)
Egy táblázat mutatja a sportolókat, keresővel és sportág szerinti szűréssel.

⭐ Kedvencek oldal (favorites)
Csak azok a sportolók jelennek meg, akiket a felhasználó kedvencnek jelölt.
